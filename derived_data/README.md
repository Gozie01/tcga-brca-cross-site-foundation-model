# Derived Data v1.0.0

Compact frozen outputs supporting cross-site TCGA-BRCA evaluation. This package contains public TCGA identifiers, derived patient-level features, predictions, metrics, calibration and ablation results, audit metadata, and manuscript tables. It contains no WSIs, GDC-controlled data, UNI weights, credentials, or patch-level embeddings.

Use `patient_features/patient_feature_index.csv` to map feature-matrix rows to public TCGA patient identifiers. Files are covered by CC BY 4.0 except where underlying TCGA/GDC terms apply.
